# Low List for ExpressionEngine

Low List lets you loop and search through character-separated lists with its Each, Has and Has Not tags. Low Search is optional.

The canonical documentation is in [`documentation/`](documentation/): [Installation](documentation/01.installation.html) and [Tag Reference](documentation/02.tags.html). Read the [published documentation](https://eeharbor.com/low-list/documentation).

The historical EE2 branch remains available [on GitHub](https://github.com/EEHarbor/low_list/tree/ee2); it is separate from the current package.

Thanks to [Loopee](https://github.com/danott/ee-loopee) for the inspiration.
