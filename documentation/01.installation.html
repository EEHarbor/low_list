Installation

Compatibility

Low List’s package declares ExpressionEngine 3 or later. Use the package intended for your installed ExpressionEngine version and follow that version’s server requirements. The current changelog also records the EE6 update and verified EE7 compatibility.

Low List is a standalone template add-on. It can be useful alongside Low Search, but Low Search is optional.

Install Low List

  1. Download and unzip the Low List package.
  2. Copy the low_list folder into your site’s system/user/addons/ directory.
  3. In the ExpressionEngine control panel, open Add-On Manager and install Low List.
  4. Continue to the Tag Reference to use the Each, Has and Has Not tags.
